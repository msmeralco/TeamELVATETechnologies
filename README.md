# Meralco Go

A submission for the Meralco Hackathon — Category 2 (Know Your Bill, Manage Your Usage) and Category 3 (Grid Intelligence from Connected Devices). Builds on our prior project, **LINAW**, extended with LoRaWAN-based smart meter/IoT data to predict customer consumption and bills.

The system includes an admin website, a customer app (with a slider to view predicted bills), and three APIs: **EMessage** (Meralco notifies consumers of anomalies like illegal "jumper" connections), **EReport** (consumers report suspected issues via a category picker), and **EGovChain** (a transparency ledger so the consumption/prediction data shown to consumers can't be tampered with).
